# Cloudinary Video Transformation Gallery

A static GitHub Pages demo for showing Cloudinary video transformations.

## Pages

- `index.html` / `videos.html` — Videos
- `transform.html` — Transform
- `showcase.html` — Showcase
- `layer.html` — Layer
- `scale.html` — Scale

The only shared assets are `styles.css` and `site.js`. No build step or server is required.
